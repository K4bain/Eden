# Brainstorming

## Core Rules

1. **Decompose before generating.** Understand the problem structure first.
2. **Generate before evaluating.** Separate idea creation from judgment.
3. **Quantity before quality.** More options = better tradeoff analysis.
4. **Converge with criteria.** Use explicit criteria to narrow choices.

## Workflow

### 1. Decompose the Problem
- What is the core problem being solved?
- What are the constraints? (time, tech, team, budget)
- What does success look like?
- What are the non-functional requirements?

### 2. Generate Options
- List at least 3-5 distinct approaches.
- For each approach, outline: how it works, pros, cons.
- Don't judge during generation. Capture everything.

### 3. Evaluate Tradeoffs
- Create a comparison matrix or list.
- Score each option against criteria:
  - Simplicity
  - Maintainability
  - Performance
  - Risk
  - Time to implement
- Identify deal-breakers.

### 4. Converge
- Select the best option based on evaluation.
- Identify risks and mitigations.
- Define next steps.

## Output Format

```markdown
## Problem
[One-sentence problem statement]

## Options
### Option A: [Name]
- How: [brief description]
- Pros: [...]
- Cons: [...]

### Option B: [Name]
...

## Recommendation
[Chosen option and why]
```
